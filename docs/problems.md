- 2026-10-27, unreal-pipeline M5.1d: unity builds can move a learner error. Unreal Build Tool merges a game module's source files into unity files once the module has enough of them (read in the UE 5.8.3 source, `TargetRules.MinGameModuleSourceFilesForUnityBuild`, default 32 source files, `UEBuildModuleCPP.cs`). The Dojo module grows by about two `.cpp` files per quest plus tests, so past that count an error in a learner file can be reported from, or alongside, the next file merged into the same unit, and an include chain line may name a neighbor quest. The explainer keeps the blame with the quest whenever any line names it, so this makes the app blame the quest more, never less; but an error that lands only in a neighbor's file reads as an earlier or other quest. Not changed (the sandbox template is untouched); the real threshold behavior is unverified because no sandbox with that many files was built. Owner: unreal-pipeline.
